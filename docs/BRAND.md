# Rayburst Connect brand

Product: **Rayburst Connect**. Package: `rayburst-connect`.

Trace the stream, bridge the void.

`public/icon/icon.svg` is the artwork source. WXT's official auto-icons module builds
the required PNG sizes and manifest entries. UI surfaces use the source SVG directly.
`docs/brand/banner.png` is the approved English README banner.

The default color seed is `#7B3ED1`. Light and dark themes use Material Color Utilities,
with separate semantic colors for information, warnings, errors and success. The
popup, options and media frame share the theme module and pre-mount bootstrap.

Use Rayburst Connect for the extension and Rayburst for the desktop destination.
Names are not translated. Use the slogan in promotional material; use direct action
labels in the interface. Review all project prose with Sepia.
