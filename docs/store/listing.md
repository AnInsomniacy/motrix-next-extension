## Description

Rayburst Connect discovers downloadable media and hands browser downloads to the
Rayburst desktop app. Find HLS/DASH sources, choose available tracks and an output
container, or send a link directly from the browser's context menu.

Automatic interception, site rules and observed request context route downloads
according to your preferences. The popup shows desktop connection and task status.
Settings and diagnostics stay local. Cookie and request-header forwarding can be
controlled in settings. The extension does not upload browsing activity or include
analytics. See the repository's Privacy Policy for data access and retention.

Requires Rayburst and matching Extension API settings. The extension does not
transfer or mux streaming media itself. Protected media and site-specific
extraction are outside its supported scope.
